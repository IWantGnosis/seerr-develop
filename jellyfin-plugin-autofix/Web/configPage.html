AutoFix — Automated Movie Matcher & Artwork Healer

Permanently eliminates blank grey boxes in Jellyfin by pre-cleaning messy torrent/download release names, resolving TMDb IDs, and automatically injecting posters and backdrops.

Core Healing Features

Strips release tags (1080p, WEB-DL, 10bit, Dual Audio, MoviesMod, etc.), replaces dots and underscores with clean spaces, and isolates the movie title & year before Jellyfin searches.
If direct search yields zero matches, automatically retries without release year and searches franchise root keywords to guarantee a TMDb match.
Automatically pulls primary poster, backdrop, and logo images directly from TMDb, ensuring items never display as blank placeholder squares.
⚠️ Advanced: When a match is verified, safely renames the file on disk to standard format: Movie Title (Year) [tmdbid-XXXXX].ext.

API & Custom Filters

If left blank, the built-in community TMDb API key will be used automatically.
Comma-separated list of release groups, trackers, or website domains to strip from filenames.

💡 Scheduled Healing

AutoFix registers a scheduled task in your Jellyfin Dashboard under Server → Scheduled Tasks → AutoFix: Heal Missing Posters & Metadata.

You can click Play on that task at any time to run a full sweep across your existing library and heal all grey squares.
